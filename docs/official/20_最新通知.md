**📢 初赛更新公告：新增附加赛题 Task 2**

感受到大家对赛事的热情和对赛题的深入讨论，我们在初赛中更新了一道附加赛题——Task 2: 多物理环境预测。

**为什么新增 Task 2？**
Task 1 考察的是固定物理参数（Nu=0.001）下的预测能力，模型只需学习单一物理环境的演化规律。然而，真实的科学计算场景往往面临多变的物理条件：流体粘性系数可能因温度、介质等因素而变化。
Task 2 正是为此而设：我们希望探索神经算子能否自主学习物理参数带来的变化，在不同粘性系数条件下实现泛化预测。这道赛题更加开放，也更贴近实际科研需求——一个优秀的PDE Agent 不仅要能复现已知场景，更要具备举一反三的能力。

**Task 2 的特点**

* 训练数据提供 Nu 值，选手可自行决定如何利用这一信息（作为条件输入、用于数据增强等）
* 测试数据不提供 Nu 值，模型需仅基于初始条件进行预测
* 鼓励大家充分探索，训练时间不计入评分范围，但为了防止算力过度消耗，总时长需控制在12小时内
* 推理时间需在 2 分钟以内

**其他更新**

针对大家前期的疑问，我们也更新了赛事说明和 Q&A，包括：

* GPU 时间折算系数（支持 V100、RTX 4090 等多种 GPU）
* 评分规则的详细说明
* 提交格式的进一步澄清
